Лабораторная работа: генератор экзаменационных билетов
Тип приложения: консольное

Язык: любой (Python, C#, Java, Node.js, Go)

Хранилище: файл Excel

Задача
Написать консольное приложение, которое запрашивает фамилию и имя студента, генерирует номер экзаменационного билета и дописывает запись в Excel-файл.

Работа приложения
1. При запуске выводится подсказка: Для выхода нажмите ESC.
2. Приложение запрашивает Last name: — ввод подтверждается Enter.
3. Приложение запрашивает First name: — ввод подтверждается Enter.
4. Генерируется номер билета от 1 до 20.
5. Номер выводится в консоль: Билет № 7.
6. Запись дописывается в Excel-файл.
7. Приложение возвращается к шагу 2 и ждёт следующего студента.
8. Нажатие ESC в момент ожидания ввода завершает работу приложения.
Формат файла
Файл journal.xlsx. Если файла нет — создаётся с шапкой. Если есть — данные дописываются в конец, существующие строки не изменяются и не перезаписываются.

Обязательные требования
Сохранение после каждой записи. Файл сохраняется сразу после ввода каждого студента, а не при выходе из приложения. Если приложение аварийно завершится или компьютер выключится, все ранее введённые записи должны остаться в файле, а следующий запуск должен продолжить дописывать строки после них.

Проверка ввода. Пустая строка не принимается — приложение повторяет запрос. Пробелы по краям обрезаются.

Обработка ошибок. Если файл journal.xlsx открыт в Excel и недоступен для записи, приложение выводит понятное сообщение и предлагает закрыть файл, а не завершается с ошибкой.

Техническое замечание по ESC
Стандартное чтение строки (input(), Console.ReadLine(), Scanner.nextLine()) не позволяет перехватить ESC — эта функция ждёт Enter. Возможные решения:

• Проверять нажатие ESC перед вводом фамилии: считать одну клавишу (Console.ReadKey() в C#, msvcrt.getch() в Python на Windows, readchar кроссплатформенно). Если это не ESC — использовать её как первый символ фамилии и дальше читать строку обычным способом.
• Читать ввод посимвольно и самостоятельно собирать строку, обрабатывая Enter, Backspace и ESC.
Первый вариант проще и достаточен.

Проверка результата
9. Запустить, ввести трёх студентов, выйти по ESC — в файле три строки и шапка.
10. Запустить снова, ввести двух студентов — в файле пять строк, первые три не изменились.
11. Закрыть приложение через диспетчер задач после ввода студента — запись в файле сохранилась.
12. Открыть journal.xlsx в Excel и попытаться ввести студента — приложение сообщает об ошибке и не падает.
13. Нажать Enter на пустом поле — приложение повторяет запрос.
