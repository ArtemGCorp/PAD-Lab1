# План реализации: генератор экзаменационных билетов (Go)

Консольное приложение на Go: запрашивает фамилию и имя студента, генерирует номер
билета 1–20, дописывает запись в `journal.xlsx`. Выход по ESC.

## Окружение

- Go 1.26.2 (darwin/arm64) — установлен.
- Целевая платформа разработки: macOS. Код держим кроссплатформенным (см. §2).

## Зависимости

| Пакет | Назначение |
|---|---|
| `github.com/xuri/excelize/v2` | чтение/запись `.xlsx` |
| `golang.org/x/term` | raw-режим терминала для перехвата ESC |

```
go mod init pad-lab1
go get github.com/xuri/excelize/v2
go get golang.org/x/term
```

`golang.org/x/term` работает и на Windows, и на Unix — в отличие от варианта с
`msvcrt`/`readchar` из задания, здесь один код без платформенных ветвлений.

## §1. Слой хранения — `internal/journal/journal.go`

1. Константы:
   ```go
   const fileName = "journal.xlsx"
   const sheetName = "Sheet1"
   var headers = []string{"Last name", "First name", "Номер билета", "Дата и время"}
   ```

2. `Append(last, first string, ticket int, when time.Time) error`:
   - Файла нет → `excelize.NewFile()`, записать шапку в строку 1
     (жирный шрифт через `f.NewStyle` + `f.SetRowStyle`, ширины колонок
     через `f.SetColWidth`).
   - Файл есть → `excelize.OpenFile(fileName)`.
   - Номер следующей строки: `len(rows)+1`, где `rows, _ := f.GetRows(sheetName)`
     (`GetRows` отсекает пустые хвостовые строки).
   - Запись: `f.SetSheetRow(sheetName, fmt.Sprintf("A%d", n), &[]any{last, first, ticket, when.Format("2006-01-02 15:04:05")})`.
   - Дату/время пишем строкой фиксированного формата — предсказуемо и не зависит
     от локали Excel.

3. **Атомарное сохранение** (требование «сохранение после каждой записи»):
   ```go
   tmp := fileName + ".tmp"
   f.SaveAs(tmp)        // excelize всегда перезаписывает файл целиком
   os.Rename(tmp, fileName)  // атомарно в пределах одной ФС
   ```
   Убийство процесса в момент сохранения не оставит обрезанный `journal.xlsx`:
   либо старая версия, либо новая. Закрывает проверку №11.

4. **Определение занятости файла** (требование «файл открыт в Excel»):
   - Типизированная ошибка `var ErrLocked = errors.New("journal.xlsx занят")`.
   - Предпроверка: наличие файла-блокировки Excel `~$journal.xlsx` в той же папке.
   - Постпроверка: `errors.Is(err, fs.ErrPermission)` на `SaveAs`/`Rename`.
   - Обе проверки нужны: `~$`-файл — единственный надёжный признак на macOS,
     где Excel не держит жёсткую блокировку; `fs.ErrPermission` — рабочий путь
     на Windows.

## §2. Клавиатура — `internal/keys/keys.go`

5. `ReadFirstKey() (byte, error)`:
   ```go
   old, err := term.MakeRaw(int(os.Stdin.Fd()))
   defer term.Restore(int(os.Stdin.Fd()), old)
   ```
   Читаем **один** байт из `os.Stdin`. Терминал восстанавливаем до возврата.

6. `PromptWithESC(label string) (string, bool)` — реализует вариант 1 из задания:
   - вывести `label`, прочитать одну клавишу;
   - `0x1b` (ESC) → вернуть `("", false)` — сигнал выхода;
   - `0x03` (Ctrl+C) → тоже выход. **Обязательно**: в raw-режиме сигналы
     отключены, без этой ветки Ctrl+C перестанет работать;
   - `0x0d`/`0x0a` (Enter) → вернуть пустую строку, вызывающий повторит запрос.
     В raw-режиме Enter — это `CR` (`0x0d`), а не `\n`;
   - `0x7f` (Backspace) первой клавишей → игнорировать, перечитать;
   - любой другой символ → напечатать его вручную (в raw-режиме эхо выключено),
     затем добить строку обычным `bufio.NewReader(os.Stdin).ReadString('\n')`
     и склеить с первым символом.

7. `Prompt(label string) string` — обычный `bufio` без raw-режима, для поля
   `First name:` (по шагу 8 задания ESC нужен только в момент ожидания фамилии).

## §3. Цикл приложения — `main.go`

8. Стартовая подсказка: `Для выхода нажмите ESC.`
9. Бесконечный цикл:
   1. `Last name:` через `PromptWithESC` → `false` означает выход из программы.
      `strings.TrimSpace`, пустая строка → повторить запрос.
   2. `First name:` через `Prompt` → `TrimSpace`, пустая → повторить запрос.
   3. `ticket := rand.IntN(20) + 1` (Go 1.22+: `math/rand/v2`, глобальный
      источник уже инициализирован случайно — ручной `Seed` не нужен).
   4. Вывод: `Билет № 7`.
   5. `journal.Append(...)`.
   6. При `ErrLocked`: вывести
      `Файл journal.xlsx открыт в Excel. Закройте его и нажмите Enter для повтора.`
      и **повторить запись того же студента** в цикле, а не терять её —
      сгенерированный и показанный билет обязан попасть в файл.
   7. Вернуться к шагу 1.

## Замечания

- **excelize перезаписывает файл целиком** при каждом сохранении — истинного
  «дописывания в конец» на уровне байтов не происходит. Значения существующих
  строк сохраняются нетронутыми (требование задания выполнено), но ручное
  форматирование или формулы, добавленные в файл извне, могут быть потеряны.
  Для лабораторной это стандартный и приемлемый подход.
- **Проверка №12 написана под семантику блокировок Windows.** На macOS ветку
  ошибки фактически включает детект `~$journal.xlsx`; обработка
  `fs.ErrPermission` остаётся в коде для корректности под Windows.
- **Голый ESC vs escape-последовательности.** Стрелки и функциональные клавиши
  тоже начинаются с `0x1b`. Мы трактуем любой `0x1b` как выход — для задания
  этого достаточно. Строгий разбор потребовал бы неблокирующего чтения
  следующих байтов с таймаутом; в план не включён сознательно.
